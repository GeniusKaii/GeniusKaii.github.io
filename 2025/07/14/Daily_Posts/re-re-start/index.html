    再起！

    2025-07-14 · Kaii 谈生活

    想起来很久没有折腾我这个博客站点了。

    自从前司在国内走下坡路、甚至开始严查日常 github 访问之后（其实主要是监控上传，但是呢就是层层加码吧），我这边博客的输出就日渐减少了。
    再后来 aliyun 的云服务器也到期，更加没有花心思在这了。
    再再后来我的 geniuskaii.cn 域名也到期了……哭泣
    还是得靠摸鱼提高生产力呀！！

    于是今晚花了点时间，把博客搬到了 GitHub Pages 做一个公共访问，并做了一个域名重定向，保留了我的 kaii.fun 域名，这样省去了租服务器的钱……
    然后发现三年前做的首页单向友链们都已经停更做其他事情去了……一个不剩，令人唏嘘……

    希望可以重拾写博客的好习惯！人和人的差距在归纳和讲课！
